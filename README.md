# Rodoviário Sul Sudeste — site institucional

Site estático (HTML, CSS e JavaScript puro) da transportadora Rodoviário Sul Sudeste.
*Conectando regiões, movendo o Brasil.*

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Home: hero, ações rápidas, rastreio, números, serviços, atuação e contato |
| `sobre-nos.html` | História, missão, visão e valores |
| `servicos.html` | 8 serviços + diferenciais |
| `beneficios.html` | Benefícios de ser parceiro |
| `area-de-atuacao.html` | Cobertura, unidades e frentes de atuação |
| `cotacao.html` | Formulário completo de cotação |
| `rastreamento.html` | Consulta por remetente e por destinatário |
| `contato.html` | Canais e formulário |
| `trabalhe-conosco.html` | Cadastro de motoristas e equipe |

## Stack

Sem framework e sem build. Fontes Google (Barlow Condensed + Manrope) e ícones Tabler via CDN.
Todos os formulários montam a mensagem e abrem o WhatsApp comercial — não há backend nem envio de e-mail.

## Publicação

Hospedado na Vercel. `vercel.json` ativa URLs limpas (sem `.html`).
Cada push na branch `main` publica automaticamente.

## Imagens

Fotos do Pexels (licença livre para uso comercial). Logo e mapa derivados da identidade visual da empresa.
